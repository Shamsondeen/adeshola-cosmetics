# Adeshola Cosmetics — Frontend

React frontend for the Adeshola Cosmetics e-commerce platform.

## Features
- Product browsing, search, filtering and pagination
- Product details and cart management
- User registration, login and profile management
- Checkout and order history
- Admin dashboard for products, orders and users
- Cloudinary-backed product image uploads

## Run locally
```bash
npm install
cp .env.example .env
npm start
```

The default API is `http://localhost:5000/api`.
